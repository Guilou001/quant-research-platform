# Spécification NNN : <ce que la chose fait, en une phrase>

**Statut** : brouillon | acceptée le AAAA-MM-JJ | livrée le AAAA-MM-JJ
**Règles concernées** : les numéros de `CLAUDE.md` qui s'appliquent.

## Ce que cela doit faire

Une phrase en mots de tous les jours, puis le mécanisme. Qui appelle quoi,
avec quelles entrées, pour quelles sorties.

## Ce que le dépôt porte déjà, et qui sera appelé plutôt que recopié

Les modules, fonctions et tables existants, nommés. Une chose écrite deux fois
est une chose qui divergera.

## Les critères d'acceptation, mesurables

Une liste de mesures qu'un test ou un script rend, avec leur seuil, écrits
avant le code. Un critère qui ne se mesure pas n'en est pas un.

## Les décisions de conception, et ce qu'elles écartent

Chaque convention qui déplace le résultat, avec l'option écartée et la raison.

## Le plan, en étapes vérifiables

Numérotées. Chaque étape dit ce qui existe quand elle est finie et comment on
le vérifie.

## Hors périmètre

Ce que cette spécification ne fait pas, et où cela vivra.
