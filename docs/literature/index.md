# Lire les articles avec les études

Les fiches distinguent le texte consulté, les nombres rapportés et les calculs du laboratoire.
Certaines reposent sur une version de travail ou sur un résumé. Le statut de lecture est indiqué dans chaque fiche.

Une adaptation sur données gratuites ne devient pas une réplication exacte parce qu'un chiffre paraît proche.
Les différences de période, d'univers, de variables et d'exécution doivent accompagner la comparaison.
