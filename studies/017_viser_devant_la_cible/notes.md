# Notes de l'étude 017

## Ce qui a été décidé avant de voir un chiffre

La grille de dix taux, le choix sur la fenêtre d'avant publication de l'étude
001, le holdout lu une fois, les coûts de l'étude 001. Dix essais.

## Ce qui a surpris

Le sommet se déplace de 0,5 à 0,1 entre les deux fenêtres, et sur le holdout
le brut lui-même est le plus haut au taux le plus lent. Après publication, le
momentum de série temporelle sur ces fonds cotés est un signal qu'il vaut
mieux suivre lentement, ce qui est cohérent avec un signal dont la valeur
s'est éteinte : suivre de près un signal mort coûte, le suivre de loin coûte
moins.

## Les essais ratés

La première exécution a écrit ses résultats puis échoué à l'inscription au
registre, dont les hypothèses de coût doivent être numériques : la
configuration de l'étude 001 porte un champ vide. Filtré, relancé.

## Ce qui reste ouvert

La forme complète de l'article, avec l'escompte des signaux par leur vitesse
d'extinction, sur l'arbitrage statistique de l'étude 007, dont la rotation est
le coût qui le tue.
