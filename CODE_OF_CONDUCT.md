# Code de conduite

Le dépôt suit le [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/),
version 2.1. En une phrase : on discute des résultats, des données et des
méthodes, jamais des personnes. Un désaccord sur un chiffre se règle par une
mesure reproductible, et une critique s'écrit avec la commande qui permet de la
vérifier.

Un comportement contraire se signale par courriel à l'adresse indiquée sur le
profil GitHub de l'auteur. Le signalement reste confidentiel.
